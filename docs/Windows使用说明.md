# Island For Windows 使用说明

适用版本：1.0.0。面向 Windows 10 / 11 的 64 位电脑，使用与 Island For Mac 相同的小岛图标和页面风格。

## 1. 启动、升级与退出

1. 将交付的 ZIP 完整解压到固定文件夹，再双击 `Island.exe`。不要直接在压缩包中运行。
2. 将鼠标停留在屏幕顶部的小岛上即可展开；移开后收起。没有刘海的显示器也可使用。
3. 点击标签切换模块，点击齿轮进入设置；右键小岛或任务栏通知区图标，也可打开设置。
4. 退出时使用右键菜单中的“退出 Island For Windows”。升级前先正常退出旧版，再替换程序文件。

程序文件已统一为 `Island.exe`，文件属性中的产品名为 `Island For Windows`。数据目录继续使用 `Poni`，更换名称不会清空原有待办、暂存区和专注记录。本定制版不接收上游自动升级；请使用新的交付包升级。

从 0.0.6 或更早版本升级时，先正常退出旧程序，再将新包完整解压并运行 `Island.exe`。不再运行旧 `poni.exe`。已有开机启动记录会在新版首次运行时更新为当前程序路径；内部注册名继续保留，以保留 Windows 已记录的启用或禁用状态。原先未开启的启动项不会自动开启。旧 Codex Hooks、notify 或 MCP 配置如果指向 `poni.exe`，需按随包说明改为 `Island.exe`；仅改文件名不能自动修改这些外部配置。

若出现“更改尚未保存”，先查看原因并重试。直接结束进程可能丢失尚未保存的修改。

## 2. 显示器、主题与字体

在“设置 → 灵动岛”选择主显示器，或“启动时鼠标所在显示器”。后者在启动或修改选择时确定位置，之后不会跟着鼠标在两块屏幕间移动。也可沿屏幕顶部横向拖动收起的小岛；右键菜单可恢复居中。

“外观”中可切换主题、待机样式和界面字体：

- 点击“界面字体 → 选择字体”，选择 Windows 已安装的字体。
- 使用新的字体文件时，先通过 Windows 安装 `.ttf` / `.otf`，再到应用中选择。
- 选择只改变字体族，保留界面的字号和粗细层级；中文和缺失字形继续由系统回退字体补足。
- 点击“恢复主题字体 → 恢复默认”使用主题原有字体。字体被卸载或不可用时会回退。

“标签页 → 打开上次所在位置”控制再次展开时是否记住页面。全屏应用中的隐藏、置顶和游戏读数在“灵动岛”中单独设置。

## 3. 音乐与歌词

先在 QQ 音乐、网易云音乐或 Apple Music 中播放。播放器向 Windows 提供媒体信息后，小岛显示歌曲、封面和进度。播放、暂停、切歌和跳转是否可用，取决于播放器提供的系统控制能力。

多个应用同时播放时，优先显示正在播放的 QQ 音乐、网易云或 Apple Music；浏览器视频等其他音频不会抢占它们。多款音乐播放器同时播放时，保持当前音乐播放器。当前音乐暂停、退出或读取失败时，再选择其他可用会话；岛内播放控制跟随所显示的播放器。

打开音乐标签、重新展开音乐页，或在解锁、亮屏及退出节电状态后，软件会重新检查播放器。启动列表为空、媒体读取暂时失败或歌名尚未就绪时，最多自动重试三次；这些延迟重试在锁屏、熄屏或节电时暂停，不会持续轮询。暂时读不到进度时仍显示已取得的歌曲信息和基础控制，进度恢复后再启用拖动跳转。

网易云需先在“设置 → 系统”勾选“开启 SMTC”。若未开启，Windows 不会向小岛提供该播放器的媒体会话。小岛不会替你修改播放器配置。

网易云 3.1.x 的 SMTC 可能只提供歌曲、不提供时间轴。0.0.5 只读网易云本机播放事件，取得实际歌曲 ID、专辑、总时长，并依据实际开始播放、暂停恢复和进度跳转事件同步歌词。没有完整歌曲信息时，按实际 ID 从本机播放队列补齐，不以同名歌曲猜录音。最小化不会影响这条读取链路，无需还原网易云窗口或另跑采集脚本。

只在网易云播放且系统缺少时间轴时每秒读取日志新增部分；暂停后停止重复读取，系统媒体事件会触发恢复读取。切换播放器、锁屏、熄屏和节电后停止。启动和长时间休眠恢复后最多回放最后 4 MiB 事件；日志暂时不可读、版本格式不受支持或缺少实际位置事件时，显示“播放进度暂不可用”，仍可浏览已取得的歌词。换曲不继承上一首位置，预加载下一首不会被当作已经播放。不能据此开启网易云未提供的拖动跳转控制。

歌词只使用当前播放器对应的服务：QQ 音乐使用 QQ 歌词，网易云使用网易歌词，Apple Music 使用 Apple Music 歌词。匹配时会核对歌曲、歌手、时长和版本；服务没有对应录音的同步歌词时，不会借用另一个平台的歌词。播放器自身能显示歌词，不代表它会把歌词直接共享给其他应用。

Windows 网易云只提供歌名和歌手、缺少专辑与时长时，软件会在网易云服务中检查歌名、歌手和录音版本，完整核对候选后仅采用唯一匹配。存在多个同名录音或无法检查完整候选时暂不显示，避免现场版、伴奏和其他录音错配；之后播放器补充信息时会重新匹配。

- 在歌词区上下滚动可浏览其他句，点击“回到当前”恢复跟随。
- 在“设置 → 音乐和歌词”调整歌词时间偏移、当前句颜色，或恢复默认颜色。
- 关闭同步歌词后仍可查看歌曲和播放控制。
- 音乐页的进度条控制播放位置，带扬声器图标的音量条控制系统输出音量；点击扬声器可一键静音、取消静音。

Apple Music 歌词需要自己的有效账户令牌。右键菜单中打开“Apple Music 歌词 → 如何获取令牌”；复制自己的令牌后，使用“使用剪贴板中的令牌”。令牌仅供自己的账户使用，不能随程序分享；失效后重新获取，也可用“移除令牌”清除。令牌在本机加密保存。

## 4. 日历、待办与天气

“今天”左侧显示完整月历和农历，使用月份切换按钮查看其他月份，点击“今天”回到当前日期。点击某一天，右侧显示对应日期的待办。有待办的日期会着色，并区分仍有未完成事项和全部完成。

右侧待办标题始终显示完整年月日，选中今天与其他日期的格式一致。

在右侧输入待办并按回车保存。使用拼音时，先确认候选汉字，再按一次回车保存。复选框可完成或恢复事项，列表支持滚动、删除、清除已完成及短时撤销。

今天会继续显示此前未完成的事项；其他日期按该事项的计划日显示。添加和清除操作针对当前选中日期。

天气卡片支持手选城市和一次性定位。点击城市名输入至少两个字，从候选列表中选择正确地区；选择会保存，重启后继续使用。只有点击“定位”时才申请系统定位权限；定位不可用时可继续手选城市。天气仅在“今天”页打开时查询和刷新，需要联网。

## 5. 文件暂存区

把文件或文件夹拖到小岛上，松开后加入暂存区，最多保留 24 项。点击条目打开，右键在资源管理器中定位，按住拖到其他应用。移除和清空支持短时撤销。

暂存区保存的是原文件路径，不复制、不移动、不上传文件。移除条目不会删除原文件；原文件被移动或删除后，条目可能变暗并无法打开。

添加时会检查重复路径；同大小文件进一步比较 SHA256 内容摘要，内容相同的文件不会重复加入，文件夹按实际路径去重。内容检查在后台完成，大文件可能稍后出现。原文件修改后，下次添加会重新检查，不沿用旧摘要。文件读取失败时保留引用，并在日志中记录检查失败。

“设置 → 文件暂存区 → 添加文件提示音”只在新文件成功加入时发声，重复添加不播放。

## 6. 专注

“专注”提供专注、短休息和长休息。空闲时可选择阶段；开始后可暂停、继续、重置或跳过。在设置中调整各阶段时长、长休息间隔，以及是否自动进入休息或下一次专注。

自然完成一次专注才计入今日完成次数；主动跳过、暂停或重置不会增加次数。阶段结束显示完成提醒；未自动开始下一阶段时，可点击提醒中的开始操作。收起小岛后计时继续显示。

“设置 → 专注 → 专注提示音”控制专注操作和阶段结束声音。

## 7. 微信提醒与声音

在“设置 → 弹出提示 → 微信”中分别控制“微信消息提醒”和“微信提示音”。右键菜单也可开关微信提醒。

微信在后台触发任务栏闪烁时，小岛显示“微信有新消息”，点击可打开对应微信窗口。它不读取聊天内容、联系人或微信数据库，也不显示发送人和正文。

同一轮闪烁只提醒一次；打开微信后，下一轮可再次提醒。正在前台的微信不重复提醒。关闭微信提醒会撤下已有的微信卡片。锁屏、熄屏或全屏隐藏期间的展示行为受系统状态与小岛设置限制。

如果微信本身关闭了闪烁提示，或某版本没有发出 Windows 的闪烁事件，小岛就无法据此判断有新消息。此功能与必须打包安装、申请授权的 Windows 通知读取不同，普通解压版也可使用。

专注、暂存区、微信、邮件和 Codex 各有独立声音开关和“提示音类型”选择。在对应模块设置中点击当前声音名称，按分类选择后会立即试听并保存；点“恢复默认”使用下表的默认声音，取消菜单不会修改选择。微信的声音设置在“弹出提示 → 微信”中。

软件内置 25 种 macOS 原音：11 种新款、12 种常用，以及作为默认保留的“敲打电报”和“三全音”。无需另外安装音频文件，不依赖 Windows 系统声音方案；不导入其他经典/系统音效，也不支持导入外部音频。

| 模块 | 默认提示音 |
| --- | --- |
| 文件暂存区 | 敲打电报（Telegraph） |
| 专注 | 脉冲（Pulse） |
| Codex | 欢呼（Cheers） |
| 微信 | 三全音（Tri-Tone） |
| 邮件 | 竹子（Bamboo） |

开关控制自动提醒，主动选择声音时仍会试听。响度受 Windows 输出音量、系统静音和音量合成器影响；没有独立的提示音音量滑杆。

## 8. 多邮箱提醒与预览

在“设置 → 邮件”中添加账户，可同时保留多个邮箱。每个账户可单独控制启用、新邮件提醒、声音和预览隐私；邮件总开关关闭后停止收信，保留账户设置。

| 邮箱类型 | 添加前准备 |
|---|---|
| QQ 邮箱 | 在网页邮箱开启 IMAP，填写完整邮箱地址和邮箱授权码。默认服务器 `imap.qq.com`、端口 `993`。 |
| iCloud 邮箱 | 填写完整邮箱地址和 Apple 应用专用密码。默认服务器 `imap.mail.me.com`、端口 `993`。 |
| Aruba 公司邮箱 | 普通邮箱默认 `imaps.aruba.it`、端口 `993`；PEC 使用 `imaps.pec.aruba.it`。启用两步验证时，按服务商要求使用邮件客户端专用密码。 |
| 其他公司 / IMAP 邮箱 | 向管理员确认 IMAP 服务器、SSL/TLS 端口及密码或授权码。当前使用加密连接，不支持明文 IMAP。 |
| Gmail | 需要 Google Cloud 中启用 Gmail API 的“桌面应用”OAuth 客户端 ID 和客户端密钥。保存后在浏览器完成只读授权；不是直接填写 Gmail 登录密码。 |

密码、授权码和 OAuth 令牌保存在当前 Windows 用户的凭据管理器中，配置文件不保存这些明文凭据。迁移到另一台电脑或另一个 Windows 用户时，需要重新授权。

连接成功后可切换账户、查看最近邮件并点击预览；首次连接不会把历史邮件逐封弹出。后台按约 60 秒间隔检查新邮件，也可手动刷新，因此不是即时推送。锁屏、熄屏和节电状态下会暂停后台检查。“专注时静默提醒”可延后新邮件弹出。

提醒可设为仅数量、发件人与主题或含正文摘要。邮件提示音总开关和账户自己的声音开关需要同时开启才会发声。预览中的“网页邮箱”打开对应服务商网站；自定义 IMAP 未配置网页入口时不显示该操作。本 Windows 版没有邮件翻译和打开 macOS 邮件功能，也不提供写信、回复或发送邮件。

## 9. Codex 提醒与快捷回复

在“设置 → Codex 提醒”开启“启用 Codex 提醒”。仅开启此项还不会自动改写 Codex 配置；需按随包的 [Codex Windows 接入说明](codex-integration-windows.md) 配置 Hooks 或 MCP，并保留原有设置。

- Hooks 可显示本轮结束和审批提醒；审批仍回 Codex 处理。
- MCP 提供 `island_notify` 和 `island_ask`，后者可让 Codex 向岛内提出普通问题并等待你的回答。
- 查看历史和向原会话快捷回复，还需要本机 Codex CLI 支持相应历史与队列接口。仅有 `codex.cmd`、找不到原生 `codex.exe` 时，需要按接入说明补齐环境。
- “确认”会把固定文本“确认”加入对应原会话队列；自定义回复必须明确点击“发送”。“已加入队列”表示接收成功，不代表模型已处理。
- 结果未知时先核对原会话再决定是否重发，避免重复消息。原会话闲置时，请在 Codex 中打开它。
- Windows 附件卡片在资源管理器中定位文件，由你决定如何查看；不会自动执行附件。

本机连接使用当前用户专用的命名管道，无需手动填写地址，也不监听公网端口。消息、读取的历史和草稿仅在内存中；关闭接入或退出应用会清空，已经提交给 Codex 的消息不会撤回。锁屏或关闭消息预览可隐藏正文，声音在 Codex 设置中单独控制。

## 10. 数据、备份与常见问题

| 内容 | 默认位置 |
|---|---|
| 设置、待办、暂存区引用、专注记录 | `%APPDATA%\Poni\` |
| 歌词缓存 | `%LOCALAPPDATA%\Poni\lyrics\` |
| 日志 | `%LOCALAPPDATA%\Poni\poni.log` |
| 邮箱凭据 | 当前 Windows 用户的凭据管理器 |

右键菜单中的“打开数据文件夹”可直接进入数据目录。备份前正常退出，再复制 `%APPDATA%\Poni\`；恢复时也先退出程序。备份不包含暂存区引用的原文件，也不能代替邮箱重新授权。分享程序时只分享交付包，不要附带自己的数据文件夹、令牌或凭据。

歌词诊断已内置并自动写入 `poni.log`，无需额外运行采集脚本。网易云、QQ 音乐和 Apple Music 在歌曲信息、播放状态或时长发生变化时记录原始媒体信息；歌词请求还会记录匹配、接口响应、缓存、重试和显示结果。采集复用正常读取结果，不增加播放器属性读取；同时记录已有会话枚举的数量和应用标识，列表为空时也会记录。普通播放进度不新增这类记录，不记录歌词正文、邮箱凭据或 Apple Music 令牌。遇到异常时保留歌曲播放，并提供对应时间段的 `poni.log` 即可核对。

| 现象 | 检查方法 |
|---|---|
| 看不到小岛 | 查看通知区是否已启动；确认显示器选择、待机隐藏样式和全屏隐藏设置。不要连续启动多份。 |
| 歌曲不显示 | 确认播放器正在播放且已向 Windows 提供媒体信息；切歌或重开播放器后再看。 |
| 歌词不可用 | 核对当前播放器、歌曲版本、网络和 Apple Music 令牌；软件已自动记录诊断，可提供 `%LOCALAPPDATA%\Poni\poni.log`。无对应同步歌词或录音不明确时不会跨平台替代。 |
| 提示音没有声音 | 确认对应模块开关、Windows 输出/静音和音量合成器；微信还需确实触发一轮新提醒，邮件还需开启账户自己的声音开关。 |
| 输入框有光标但不能输入 | 重新点击输入框使其取得键盘焦点；确认使用的是本次新版。若候选词仍偏移，记录输入法名称、屏幕缩放比例和所在屏幕。 |
| 邮箱连接失败 | 核对完整地址、服务器、SSL/TLS 端口及授权码；Gmail 检查 API/OAuth 客户端和浏览器授权。 |
| Codex 只有提醒，不能读历史或回复 | 按专用接入说明检查原生 CLI 路径、版本能力和原会话状态。 |

本版在 Mac 上进行 Windows 交叉编译和相关静态检查。Windows 下字体选择、不同输入法与屏幕缩放、微信闪烁、邮箱授权和 Codex 实际投递仍需在目标电脑核验，编译成功不代表这些操作已在 Windows 实机全部验证。
