# 界面与字体规范

## 原则

以内容和操作为先，使用中性色层次、细分隔和有限强调；不以彩色卡框区分无关模块。不同页面保留业务结构：日历双栏、邮件列表/阅读、音乐播放器/歌词、系统数据三栏。

## 字体

样式定义只有一个来源 `crates/poni/src/text.rs`，字号在 `poni-core/src/design.rs`。Mac 使用 `NSFont::systemFontOfSize_weight`，拉丁字母由 SF 系统字体绘制，中文由 Core Text 选择系统中文字体，通常为苹方；不下载字体，不新增字体包。Oyen 的既有 Outfit 主题选择保留，其不含的字形同样由系统回退。不能把字号文本绘制与测量改成两套字体。

|角色|字号DIP|字重|使用|
|---|---:|---|---|
|辅助说明|11|Regular|短提示、字段说明|
|次要文字|12|Regular/Medium|状态、地址、元信息|
|正文/表单/控件|13|Regular，操作Semibold|待办、邮件正文、输入与按钮|
|模块标题|15|Semibold|页内标题|
|数据|18|Semibold + tabular|指标|
|独立设置页标题|20|Semibold|避免巨标题争夺内容|
|倒计时/大数值|30|Semibold + tabular|专注和天气等主要数值|

多行阅读内容保留既有 1.35–1.45 倍行高。日历农历为密集的次级读数，9 DIP；图例10 DIP，仅限固定日期网格，不推广到正文或表单。中文城市、长邮箱名称、正文与混排必须按真实 Core Text 测量；单行省略，多行换行，不以字符串长度估宽。窄按钮的内容区域必须裁剪，中文输入沿原 IME/UTF-16 边界处理，不重写原生安全输入。

## 色彩

`geom::palette` 是主题色语义入口，`Look` 映射到深浅主题。正文/次要/辅助文字分层，交互默认蓝；普通图标与hover中性；成功绿、等待/警告橙、错误红。封面、天气状态和品牌保留有含义的颜色。用户选定的歌词颜色不被主题覆盖。

邮箱名称表示连接状态：Ready绿、Connecting/Syncing/Authorizing橙、Error红、Paused/Off灰；不再叠加重复状态圆点。未读量独立分档：未知和0灰、1–4蓝、5–9橙、10以上红。部分合计保留≥；不从界面显示文本反推数字，不为颜色或角标新增服务器请求。

高级设置采用中性灰深/浅两套surface，复用账户表单背景；标题和正文由同一主题转换，不再给每个栏目彩色底。歌词默认蓝，恢复按钮同色，保留用户自选颜色。

## 间距、控件与圆角

共享间距4/8/12/16/24；按钮28/34高，设置行40/52高。普通按钮与输入框8圆角，业务面板12，独立窗口14。岛体Pill轮廓是品牌形状，单独保留40圆角，不把内部每个控件都画成胶囊。命中范围、WidgetId、Command与页面切换规则保持兼容。

## 状态与性能

加载、空、失败、暂停、未知数要区分；不把失败伪装成成功。原生表单保留验证信息、保存/取消、安全密码字段和滚动裁切。装饰不制造后台工作；天气静态符号取消4Hz唤醒。动画仅用于有限反馈或确有内容变化，不增加常驻轮询。

## 验收

在支持的480/620/900DIP检查中文/英文/长文本、按钮、下拉与实际命中；检查Pill/Classic/Glass/Oyen/Diorama及设置浅色。手机和平板不是本产品运行目标，不伪造网页响应式验收。离屏绘图、真实Canvas交互测试和实机输入/服务验收分别记录。
