# 蓝牙设备电量

展开小岛后选择“蓝牙”，查看本机已连接设备。电量由系统或设备提供；未提供时显示“电量未知”，0%是有效读数。左右耳、充电盒只显示实际存在的部件数据，不用它们计算整机百分比。

页面打开时立即读取，采集结束30秒后再次读取；“刷新”使用相同采集链路。切换页面、收起、全屏隐藏、锁屏、熄屏或省电时取消查询并停止周期等待，恢复可见后重新读取。读取期间保留上次设备列表；失败或暂停时明确标注上次读数。页面中的“蓝牙设置”打开系统设置，不在小岛内配对或管理设备。

## 系统来源

| 平台 | 连接设备与电量来源 | 兼容边界 |
| --- | --- | --- |
| Windows | WinRT已配对且已连接的Classic/BLE设备；本地PnP属性缓存优先，缺少读数的已连接BLE设备再查询标准Battery Service `180F` / Battery Level `2A19` | 取决于设备与驱动是否报告电量；不实现厂商专用协议、AirPods广播解码或额外扫描 |
| macOS | `system_profiler SPBluetoothDataType -json`连接设备与电量，IOKit HID明确的`BatteryPercent`补充键鼠；`pmset -g accps -xml`补充连接附件的左右耳/充电盒 | 系统报告字段与附件信息因系统、型号和连接状态而异；不使用私有耳机getter，不主动扫描或连接设备 |

关键连接来源全部不可用时报告读取失败；部分来源失败时保留可用列表并提示。成功空列表与读取失败分开处理。系统电量缓存可能滞后，页面显示的采集状态不代表设备刚更新了电量。

系统读取在短生命周期后台任务中进行。Windows异步枚举与GATT读取有超时及取消检查；Mac系统报告最长8秒、附件查询最长3秒，分别限制输出大小并在取消/失败时终止和回收查询进程。关闭页面不等待查询结束；应用正常退出前取消并回收当前与此前已取消的任务。同步系统调用和进程回收仍由操作系统完成，取消检查间隔不能视为整个退出延迟上限。

本功能不新增第三方依赖，不保存设备名称、地址或电量历史；设备内部ID只用于本次运行合并，不显示或写日志。原耳机连接提示继续沿用既有过滤、防抖与开关。

## 方案参考与验证范围

Mac多来源读取思路参考MIT项目[Stats](https://github.com/exelban/stats/tree/cb9317e228dae415e06cffbdeed734b46f50592e/Modules/Bluetooth)；Windows系统属性与标准服务思路参考MIT项目[BlueGauge](https://github.com/iKineticate/BlueGauge/tree/a36dfb43b7fe229407cc29f56731930482c5a103/src/bluetooth)。本适配按系统接口契约独立实现，没有引入这些项目的后台扫描机制或第三方运行库。未复制AGPL/GPL项目的实现。

编译、现有测试与离屏示例只能验证各自范围；连接、断连、电量变化、左右耳/盒与实际资源开销须在对应系统及真实设备上确认。当前不承诺全部蓝牙设备可读取电量，也不承诺所有耳机可获得部件信息。
