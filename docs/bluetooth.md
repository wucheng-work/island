# 蓝牙电量功能下线

从1.0.2起，Mac和Windows均不再提供独立蓝牙设备电量页面、手动刷新或对应的周期采集。专属设备快照、采集线程和两端系统读取适配已移除，Mac不再由该功能启动系统蓝牙报告及附件电源查询。

此次下线针对用户报告的蓝牙页面开启时耳机杂音场景，不代表已经证明某个系统接口是根因，也不保证解决其他程序、系统或耳机本身引起的全部音频问题。

原有耳机连接、断开提示保留，继续使用已有平台服务及`hud_bluetooth`开关。音乐、音量和通知提示音功能不在此次下线范围内。

旧配置记住的`bluetooth`页面键会按未知页面回退到可用页面；隐藏标签中的旧键可以继续保留，不需要删除设置、用户数据或邮箱凭据。
