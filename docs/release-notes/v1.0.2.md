# Island 1.0.2

- Mac 与 Windows 下线蓝牙设备电量页面、手动刷新入口及该页面专属的周期采集链路。
- 兼容旧版保存的蓝牙页面配置：升级后回退到有效页面，不再通过旧页面键启动电量采集。
- 保留原有蓝牙耳机连接、断开提示，以及音量、音乐和提醒等其他功能；用户数据目录与邮箱凭据标识保持一致。

本次下线源于蓝牙耳机杂音反馈。已观察到关闭蓝牙页面后恢复正常，但尚未确认具体致因；本版本不宣称已根治所有耳机杂音。

发行包使用同一源码版本构建：Mac 提供 Apple Silicon（arm64）与 Intel（x86_64）通用 DMG；Windows 提供 x64 NSIS 安装器和便携 ZIP，并附生产密钥签名的更新清单及 SHA-256 校验表。

Mac 沿用预先选定的未 Apple 公证发行策略，包内应用使用构建机测试签名；首次打开可能需要在“系统设置 → 隐私与安全性”中允许。Windows 未配置 Authenticode，安装器和应用可能出现来源提示。更新清单的来源签名不等同于 Apple 公证或 Windows 代码签名。
