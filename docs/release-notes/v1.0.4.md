# Island 1.0.4

- 点击岛上的普通 Codex 提醒或审批提醒正文，打开桌面端对应的本机会话。岛内页面的「打开 Codex」也会定位到该会话。
- 普通提醒右侧的「确认」会向原会话排队发送固定文本「确认」。岛内提问可展开并在 Island 中回答。
- 版本标签只用于标记发布。手动试打包不产生部署记录，正式发布任务负责上传并验证发行文件。

发行文件包含 Mac 通用 DMG、Windows x64 安装器和便携 ZIP，并附签名更新清单与 SHA-256 校验表。

Mac 安装包使用构建机测试签名，未经 Apple 公证。Windows 安装器和应用未经 Authenticode 签名。
