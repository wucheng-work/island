# Island 1.0.1

**Mac 与 Windows 首次统一发行，提供安装包、便携包和签名更新清单。**

- 两端使用同一份源码和版本，包含同步歌词、待办与农历日历、天气、专注、文件暂存、系统监控、多邮箱与 Codex 提醒和对话。
- Windows 调整完整设置窗口高度，使外观与字体选项完整显示；小屏幕继续使用滚动布局。
- 修复 Mac 邮件翻译桥在 Swift 6.2 下的编译兼容问题，明确使用 macOS 26 SDK；应用最低系统版本仍为 macOS 14。
- 更新仅使用本项目的签名清单和文件校验，由用户确认下载及安装。保留既有数据目录和兼容标识。

## 安装包

- Mac：通用 DMG，同时支持 Apple Silicon 与 Intel，包含 MediaRemote 框架及内置提示音。最低 macOS 14；邮件翻译要求 macOS 26 或更新版本。
- Windows：x64 NSIS 安装器与便携 ZIP。
- `latest.json` 为签名更新清单，`SHA256SUMS.txt` 用于校验下载文件。

## 签名与验证边界

本次 Mac 包采用构建机测试签名，**未通过 Apple 公证**。首次打开可能需要在“系统设置 → 隐私与安全性”中核对应用并选择“仍要打开”。Windows 安装器未配置 Authenticode，可能出现来源提示。更新清单签名用于验证发行来源与文件哈希，不代表 Apple 公证或 Windows 软件签名。

发行过程运行现有编译、测试和预览检查。此类检查不能代替真实邮箱、播放器、系统权限及不同设备上的安装验收。此前 Windows 检查曾发生一次未复现的原生访问冲突，已保留诊断，未认定根因已修复。
