# Island 1.0.1

- 新增 Mac 与 Windows 共用的蓝牙页面，查看已连接设备及系统提供的电量；不提供电量的设备明确显示未知。
- Mac 可显示系统提供的左右耳和充电盒电量；Windows 结合系统电量属性及标准BLE电量服务读取。
- 仅页面可见时采集，支持手动刷新；收起、切页、锁屏、熄屏或省电时暂停。刷新失败或暂停时保留并标明上次读数。
- 沿用现有小岛主题和导航，保留原耳机连接提示；不改变用户数据目录或邮箱凭据标识。

本次交付为本机使用的 Apple Silicon（arm64）Mac 应用与 DMG，使用本机固定证书签名，未经过 Apple 公证；不属于 Developer ID 签名的公开发行，也未生成 Windows 安装包或在线更新清单。

电量及部件兼容性取决于设备、驱动和系统提供的数据，可能存在缓存延迟。当前没有真实连接设备的电量变化、断连重连和左右耳/盒验收，不保证所有蓝牙设备都有电量读数。
