# Island 1.0.1

- 新增 Mac 与 Windows 共用的蓝牙页面，查看已连接设备及系统提供的电量；不提供电量的设备明确显示未知。
- Mac 可显示系统提供的左右耳和充电盒电量；Windows 结合系统电量属性及标准BLE电量服务读取。
- 仅页面可见时采集，支持手动刷新；收起、切页、锁屏、熄屏或省电时暂停。刷新失败或暂停时保留并标明上次读数。
- 沿用现有小岛主题和导航，保留原耳机连接提示；不改变用户数据目录或邮箱凭据标识。

发行包使用同一源码版本构建：Mac 提供 Apple Silicon（arm64）与 Intel（x86_64）通用 DMG；Windows 提供 x64 NSIS 安装器和便携 ZIP，并附签名更新清单及 SHA-256 校验表。发行说明链接指向本项目仓库，Windows 安装器包含项目许可证及第三方声明。

Mac 采用预先选定的未 Apple 公证发行策略，包内应用使用构建机测试签名；首次打开可能需要在“系统设置 → 隐私与安全性”中允许。Windows 未配置 Authenticode，安装器和应用可能出现来源提示。更新清单的来源签名不等同于 Apple 公证或 Windows 代码签名。

电量及部件兼容性取决于设备、驱动和系统提供的数据，可能存在缓存延迟。当前没有真实连接设备的电量变化、断连重连和左右耳/盒验收，不保证所有蓝牙设备都有电量读数。
