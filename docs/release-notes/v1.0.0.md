# Island 1.0.0

**Mac与Windows使用统一源码、统一版本和独立更新通道。**

- 合并两端定制功能，保留同步歌词、待办与农历日历、天气、专注、文件暂存、系统监控、多邮箱与Codex提醒和对话。
- 系统媒体、输入法、通知、邮件凭据和原生预览保留平台适配，不更改已有数据目录与兼容标识。
- 版本由Cargo workspace统一生成，增加版本、锁文件、tag和发行说明校验；后续每次新打包任务递增一次patch，同任务两端共用。
- 独立更新源只读取本仓库签名清单，校验受信公钥、版本、下载来源、大小和SHA-256；由用户检查并确认下载、安装。

此文件为1.0.0源码对应的发行说明，不代表已打包或公开发行。实际更新可用性取决于生产公钥、发行密钥及两端完整产物；Mac是否公证以具体发行说明为准。编译与单元测试不替代Windows实机、Mac权限、真实邮箱与播放器验收。
